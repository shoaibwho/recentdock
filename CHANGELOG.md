# Changelog

## 0.1.0 — unreleased (first public pre-release)

- RecentDock dock icon with a configurable left-click action (6 actions).
- Right-click menu: "RecentDock Settings" first, then four sections (Downloaded Folders,
  Downloaded Files, Opened Files, Opened Folders), each with its own on/off switch, position,
  3/5 limit, sort order and history.
- Event-driven tracking: Downloads folder monitor (Chrome-family and Firefox temp files), the
  desktop recent-files list, and Files (Nautilus) folder visits.
- Settings window with drag-and-drop ordering, per-section settings, history clearing with
  confirmation, and privacy-safe diagnostics.
- User-level `install.sh` / `uninstall.sh`.
